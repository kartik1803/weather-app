# 🌦️ Weather App

A responsive Weather Application built using **HTML, CSS, and JavaScript** that provides real-time weather information for any city using the **OpenWeatherMap API**.

## 🚀 Live Demo

[View Live Website](YOUR_DEPLOYED_WEBSITE_LINK)

## ✨ Features

- **Current Location Weather:** Get weather information based on your current location.
- **City Search:** Search for weather conditions in any city around the world.
- **Real-Time Data:** Fetch live weather information using the OpenWeatherMap API.
- **Weather Details:** Displays:
  - Temperature
  - Weather conditions
  - Wind speed
  - Humidity
  - Cloudiness
- **Responsive Design:** Works on desktops, tablets, and mobile devices.
- **Loading State:** Displays a loading screen while fetching weather data.
- **Error Handling:** Handles invalid city names and location access errors.
- **Session Storage:** Saves location coordinates to improve the user experience.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, layouts, and responsive design.
- **JavaScript (ES6+)** – Application logic and API integration.
- **OpenWeatherMap API** – Fetching real-time weather data.
- **Geolocation API** – Accessing the user's current location.
- **Session Storage** – Temporarily storing location coordinates.

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_LINK
   ```

2. Open the project folder:

   ```bash
   cd Weather-App
   ```

3. Generate an API key from [OpenWeatherMap](https://openweathermap.org/api).

4. Add your API key to the JavaScript file.

5. Open `index.html` in your browser or use the Live Server extension in VS Code.

## 🔑 API Used

This project uses the OpenWeatherMap Current Weather Data API to retrieve weather information.

API documentation: https://openweathermap.org/current

**Note:** Do not expose your private API key in a public GitHub repository. For a production deployment, use a backend to protect the key.
